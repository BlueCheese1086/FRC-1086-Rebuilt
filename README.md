# FRC 1086 Rebuilt

Java robot code for Team 1086's 2026 rebuilt FRC robot. This project uses WPILib's command-based framework with AdvantageKit logging, CTRE Phoenix 6 swerve hardware, PhotonVision/Limelight vision, PathPlanner, and Choreo.

## Robot Overview

- **Drive:** CTRE Phoenix 6 swerve drive with Pigeon2 gyro support
- **Vision:** PhotonVision cameras plus Limelight integration
- **Shooter:** multi-motor flywheel, feeder, hood targeting, and shot calculation utilities
- **Intake:** pivoting intake with roller control and simulation IO
- **Indexer:** motorized game-piece feed path
- **Autonomous:** PathPlanner autos, Choreo trajectories, and custom auto routines
- **Logging:** AdvantageKit telemetry through NT4, WPILOG, and replay mode

## Requirements

- WPILib 2026
- Java 17
- FRC Driver Station and roboRIO imaging tools for robot deployment
- Vendor dependencies already listed in `vendordeps/`

The configured team number is `1086` in `.wpilib/wpilib_preferences.json`.

## Runtime Modes

Runtime mode is controlled in `src/main/java/frc/robot/Constants.java`.

- `REAL`: selected automatically on the roboRIO
- `SIM`: physics simulation on desktop
- `REPLAY`: AdvantageKit log replay

Change `Constants.simMode` when running locally to switch between simulation and replay.

## Controls And Autos

Controller bindings and autonomous chooser options live in `RobotContainer.java`. The robot uses driver, operator, testing, and override controller ports. Autonomous routines are built from PathPlanner autos, Choreo routines, and custom command sequences.

Named PathPlanner commands are registered in `RobotContainer.pathFindToStart`, including intake and shooting actions used inside auto files.

## Logging

AdvantageKit starts in `Robot.java`.

- Real robot logs write to `/U/logs` when a USB drive is present, otherwise to the roboRIO.
- Simulation publishes telemetry over NT4.
- Replay mode reads a selected WPILOG and writes a replay output log.

Use AdvantageScope or WPILib tools to inspect NT and WPILOG data.

## Notes For Development

- Prefer editing subsystem code through each subsystem's IO abstraction.
- Keep generated code in `src/main/java/frc/robot/generated/` generated by its source tool.
- Run `.\gradlew build` before deploying changes.
- Run `.\gradlew spotlessApply` if formatting changes are needed.
- Deploy files in `src/main/deploy/` are copied to `/home/lvuser/deploy` on the roboRIO.
